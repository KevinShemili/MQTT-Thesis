Methodological note: latency is reported as mean ± 95% confidence interval across 4 independent Go benchmark runs. The confidence interval uses Student's t with df=3. Each envelope bundles a real CP-ABE ciphertext (grown from an actual TKN20 policy of the given attribute count) with a fixed-size AES-GCM nonce and ciphertext; only the marshal/unmarshal cost is timed, not the cryptography that produced the fields. Format overhead is the extra bytes each format adds beyond those raw fields.
