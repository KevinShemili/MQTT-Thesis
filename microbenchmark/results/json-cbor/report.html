Methodological note: latency is reported as mean ± 95% confidence interval across 8 independent Go benchmark runs. The confidence interval uses Student's t with df=7. Each envelope bundles a real CP-ABE ciphertext (grown from an actual TKN20 policy of the given attribute count) with a fixed-size AES-GCM nonce and ciphertext; only the marshal/unmarshal cost is timed, not the cryptography that produced the fields. Format overhead is the percentage by which serialization grows the raw field bytes.
