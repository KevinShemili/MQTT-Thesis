Key Generation

RSA: Key Size Scaling — Median, IQR, Min–Max over n Runs

Key generation is a probabilistic prime search, so its cost is a random variable with a long right tail and a single averaged figure is not representative. Each run performs exactly one generation and contributes one sample, and the distribution is reported here instead of a mean. CP-ABE is absent by design: its key issuance is performed by the attribute authority, which holds the master secret and is a trusted, unconstrained entity, so it is never a cost the constrained device pays. CP-ABE's stored key size is reported by the decrypt table above.
