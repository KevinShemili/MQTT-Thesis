Methodological Note: Latency and throughput are reported as mean ± 95% confidence interval across 3 independent Go benchmark runs. The confidence interval uses Student's t with df=2. Tag + nonce is reported as absolute bytes per message. It is not plotted because it is constant for each AEAD primitive.
