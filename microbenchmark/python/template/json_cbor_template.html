Methodological note: latency is reported as mean ± {{ConfidenceLevel}} confidence interval across {{RunCount}} independent Go benchmark runs. The confidence interval uses Student's t with df={{DegreesOfFreedom}}. Each envelope bundles a real CP-ABE ciphertext (grown from an actual TKN20 policy of the given attribute count) with a fixed-size AES-GCM nonce and ciphertext; only the marshal/unmarshal cost is timed, not the cryptography that produced the fields. Format tax is the number of bytes serialization adds over the raw field bytes.
